## 阅读与协作

Obsidian 打开 `wiki/` 作为 vault，双链按文件名解析；VS Code 可用 Foam 阅读同一批 Markdown。页面内导航以双链为准，主库根 `llms.txt` 提供 agent 与人类共用的全仓索引。Mermaid 只有在 Obsidian 配好 `internal-link` 的节点才可点击。

开工先读主库根 `AGENTS.md`、`CONTRIBUTING.md`、`ARCHITECTURE.md`、`llms.txt`，再读开发管理的状态、看板与风险判据。文档进 `wiki/`，源码进 `repos/`；运行中的临时脚本与中途输出放 `workenv/`，用户指定的正式开发证据按主库 AGENTS 的归档例外保存。页形使用单 H1、UTF-8、LF、无 BOM，文档校验命令为 `python -X utf8 wiki/format/check-md.py`。
