| 组成        | 是否随电脑变 | 原因                                                                                                                                            |
| --------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 权重        | 固定     | ≈ 文件大小，任何机器相同                                                                                                                                 |
| 激活 / 中间张量 | 基本固定   | 同模型同输入时确定，但受库版本和算子优化影响，微软官方案例 ORT 优化可把内存从 370MB 压到 80MB [4]                                                                                   |
| 框架与运行时    | 差别最大   | 线程池按 CPU 核数起线程，核越多线程栈和缓冲越多（ORT 官方文档专门提到 64 核以上线程池行为不同 [5]）；分配器会保留缓存，空闲内存不归还，实测 ORT 空闲仍占数 GB 级 [6]；Python + numpy + OpenCV 导入本身就有 150–200MB 基线 |
