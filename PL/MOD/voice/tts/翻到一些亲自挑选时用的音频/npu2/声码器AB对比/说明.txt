====================================================
怎么听：同一编号的 A 和 B 是**同一句话**，只是声码器不同。

两个声码器的差别：
  A = vocos      频域三分量(mag/cos/sin) + 图外 iSTFT
                 19.29 ms   31.3 MB   与 CPU 相关 0.969-0.978
  B = HiFi-GAN v2 直出时域波形，无 cos/sin、无 iSTFT
                 182.51 ms   7.2 MB   与 CPU 相关 0.9984-0.9997

请注意：**音色不同是正常的**——它们是两个不同的声码器。
数值只证明"NPU 忠实于自己的 CPU 版"，不证明哪个更好听。
这一项只能靠耳朵定。

音量已经接近（rms 差 <5%），不需要调音量。

结论（2026-11-02）
----------------------------------------------------------------
听完确认：两个声码器都不错。

  A = vocos      —— 19.29 ms，31.3 MB，与 CPU 相关 0.969-0.978
  B = HiFi-GAN v2 —— 62.88 ms（PRelu 提速版），4.4 MB，相关 0.9984-0.9997

两条路都成立，选型看权衡：
  要最快      -> A（比 B 快 3.3 倍）
  要省内存/去掉 iSTFT -> B（模型只有 A 的 14%，直出波形）

注意：0.998 这类数字只证明"NPU 忠实于 CPU"，不证明好听。
      "好听"是听出来的，这两件事分开记。
