# intro
我主要负责 FPGA PL 端的人脸识别视频预处理链路设计与验证。 项目采用 YuNet + SFace 双模型方案，其中 YuNet 负责检测人脸位置及关键点，SFace 负责提取人脸特征并进行身份匹配。我的工作重点是为后续模型推理提供稳定、符合输入要求的图像数据。

PL 端主要涉及三个核心模块：

1. 帧控制模块（frame_ctrl）：通过行列计数和帧同步信号管理视频数据，根据后级处理能力实现帧率控制，例如从 60fps 降至 30fps。

2. 图像缩放模块（resize）：将输入图像缩放至 YuNet 所需分辨率，并根据需要进行等比例缩放与补边，同时考虑检测坐标与原图之间的映射关系。

3. FIFO 缓存与握手模块：利用 FIFO 缓冲上下游数据，通过 valid/ready 等握手信号控制读写，处理数据速率不匹配的问题，避免数据溢出或丢失。

我的核心工作是理解各模块的数据流与时序关系，完成 RTL 仿真、边界情况验证及上板联调。 YuNet 检测后的人脸对齐、SFace 特征提取和身份匹配主要由后端软件及模型推理部分负责。

此外，还需要保证后级能够获取适合 SFace 人脸对齐的图像，不能仅依赖缩小后的 YuNet 检测输入。
