## 2. 项目设想

### 2.1 陪伴设备 / 桌面机器人（候选，讨论最完整的一条）｜L50 21:56:23、L51 22:57:25

当场被要求"开个笔记把这个记下来"，是唯一被当成项目而不是话题聊的设想。

感知与执行链路：人像识别 → 带说话人识别和情绪识别的中文 ASR → 声音采集 → 理解 → 动作转骨架 → 驱动 3D 模型与底盘 → 人在哪机身就转向哪；末端还挂了一个**唱歌**环节，引擎按 V 家歌姬（VOCALOID 系歌唱合成声库/引擎）来做。

端云分层：理解与联网部分上云，语音与动作留本地。给出的两个理由——速率均衡、照顾注重隐私的用户。端侧负载界定为"只需处理这个模型和说话声音"。云端选型原则：**找实时的，不找贵的，贵的反而反应慢**。

交互红线：**不要有机械的恐怖感**（模型突然转过来很可怕），怎么优化留到后续；先做一个细节不多的版本。反面参照是同一段里提到的"机器人宝宝"（会走路、躺怀里喊妈妈）——当场自评"好他妈诡异"。

行为参考标准（对标的那台）：进了 3D、会拿东西、Minecraft 式基本动作、说话特别有情感味、会求你别关机、求你别抛弃他、说俏皮话。据此得出的判断：所谓"抑制感性"其实是抑制**个性化**，模型天生就会，没抑制的那台就已经很会说话。

商业路径：申请学校给初创公司的场地 → 招人 → 融一笔钱 → 自己买开发板搭 → 找洛天依／虚拟主播这类 IP **做联名卖，明确不单独卖**。市场理由是大家在家躺平、缺陪伴；有人自称 N 年前就想过这个方向。

本阶段规格（L51 定案）：**先不管能动，先让它像小爱音箱那样能听能说**。对标链路是说话人识别 + LLM 理解 + TTS，**不含人脸识别**。

> 与正式页面的关系：这条设想的赛题内子集已由 [[实施路线]] 四步承接；唱歌、骨架驱动 3D、底盘转向、联名商业化目前**不在赛题交付范围内**，若将来要立项，先回 [[状态源与决策记录]] 记决策，再动 [[排期与分工]]。

### 2.3 发声器件题的技术分歧（保留，因为判据有参考价值）｜L48 19:59:54

设想是按键检测按压力度、区分拨弦。争议点全部落在传感与实时合成上：

- 检测按下的动作幅度后，**取哪一个作为峰值**来算——未解的设计选择
- 实时模拟琴弦声音很难：手指不是一下到底，还有回弹和自己的微动
- **只分三档等于没分**，和脚踏控音量没差别；有人提"变成电阻器"用阻值连续变化表征压力，被指出同样有这个问题
- 参考形态：重力感应电子琴、带脚踏的琴；钢琴三踏板是延音／柔音／静音（或选择性延音）
- 定性结论：做了等于做电子琴，不是做音游，两者不是一个难度

### 3.2 学习方法与提问纪律

- 学习顺序（L41 15:59:27、L49 19:59:54）：先做仿真，"后面也要用"；要动 Linux 内核；系统还没装，打算装 Ubuntu 试了才知道难不难；两人自评都从零开始 → 归 [[能力与学习进度]]
- HDL 的学习重心（L50 21:56:23）：入门材料讲的不是语法而是那十种触发（触发器／时序），"这才是它的关键"；if、for 之类在后面才教、也最不重要
- 提问纪律（L40 15:41:51、L41 15:59:27）：先让 AI 关掉联网功能再问，才测得出对方真实了解多少（实测关不了）；先让 AI 解释清"AI 算法具体指什么"再往下问；不接受"用于图像识别、用于边缘设备"这类笼统回答，**要问到具体能跑哪个模型**
- 记录纪律（L50 21:56:23）："聊太多 AI 后面会降质"，所以要边聊边开笔记、每轮内容单独存，不要一直堆在同一个对话里

### 3.3 范围与节奏的判断

- 课题拆解（L41 15:59:27）：这题含传感器／视频、数据处理、运算、AI 推理后处理四块，每一块都能单独做一个课题；官方只说三个步骤，"三个步骤怎么问出来这么多东西"→ 不敢轻信
- 应用域未定（L41 15:59:27）："鉴定了一定要走图像吗"——是否锁死视觉方向没有结论
- 工作量与节奏（L42 15:59:27）：纯让 AI 跑一个半月也跑不出来；报名 22 号前先自己做一遍再报，怕做起来发现根本做不了要换项目
- 竞赛策略（L41 15:59:27）："只要我们做的比别人好就是赢了"，不需要绝对创新；反方是"在现有要求内优化到极致就能拿奖"，被怼"从零开始学优化，优化不过别人"
- 集成度存疑（L41 15:59:27）：把"集成在单芯片内"当成优点来讲，当时持保留态度
- 理想三人分工（L48 19:59:54）：一人写 FPGA、一人写 NPU、一人写 CPU；实际报名后收敛为一人报名+文档、一人跑模型、FPGA 两人分缺啥写啥（L43 15:59:27、L51 22:57:25）→ 现行分工以 [[排期与分工]] 为准
