# 身份认证与意图路由

## 双模态身份认证

- **人脸链路**：NPU 人脸特征提取（MobileFaceNet／ArcFace 候选，流程为 人脸检测 → 裁剪／对齐 → embedding → CPU 身份比对）→ CPU cosine similarity + 本地身份库比对 → 身份事件。
- **声纹链路**：NPU 说话人识别（CAM++ 候选）。
- 人脸与声纹融合为**双模态身份认证**，关联设备操作权限：认证通过 → 权限与业务逻辑；认证失败 → 拒绝操作。
- 目标／人物检测（YOLOv8n 候选）形成目标事件，用于唤醒视觉链路。

> 优先级说明：**人脸为主，声纹可选**。CAM++ 保留为可选功能、列为 P2——因为已有视觉身份链路（已确认决策，见 [[09-开发计划]]；选型详情见 [[07-组件选型]]）。
>
> **待验证**：第一版演示中身份事件最终触发的具体业务动作——「开门／开放权限」目前属于示例，不视为已确定产品功能（见 [[11-待验证清单]]）。

## 意图识别与路由

意图识别采用**规则 + 关键词 + 状态机**（已确认首选）：演示稳定、零训练、低延迟，控制逻辑不依赖 LLM 幻觉；意图种类明显增加、规则难维护时再升级为小型分类模型或本地 LLM 分类。

| 意图 | 路径 |
|---|---|
| 普通本地问答 | 本地 LLM（Qwen2-0.5B-Instruct 候选）——简单且不需要联网的问答 |
| 复杂文本问答 | 云端文本 LLM（统一 API，暂不绑定单一服务商） |
| 需要看图（「这是什么／这个怎么用」） | 触发摄像头抓拍 → PS JPEG 压缩（单帧）→ 云端多模态 VLM |
| 读取文字（「这上面写了什么」） | 触发 OCR → 文本 → LLM |
| 身份相关操作 | 身份认证（人脸／声纹）→ 权限与业务逻辑 → 设备权限／控制事件 |

## 端云混合问答策略

- 普通问答由端侧 LLM 与 TTS 处理；复杂与看图问题交由云端大模型。
- 复杂图像理解走云端 VLM；文字读取走 OCR——**不把所有图像请求都送 OCR**（已确认决策）。
- 按需抓拍使用 JPEG（「这是什么」只需上传图片，不需要视频流编码）；不在当前周期自研 H.264／H.265 或 FPGA JPEG。
- 云端组件（文本 LLM／VLM／TTS）均按 API 稳定性、成本、速度、效果随时切换，不绑定厂商。

## 语音输出

| 方案 | 说明 |
|---|---|
| 主方案：云端 TTS | 自然度高，板端零模型部署压力（网络依赖） |
| 离线兜底：拼音音节拼接 | 可生成任意普通中文组合；实现简单、完全离线（机械但可靠）；若 CPU 轻量 TTS（如 Piper）实测速度足够可升级 |

输出经 ALSA（USB Audio）→ USB 音箱。
