# 组件总览与阅读地图

本目录按**组件**拆解 `repos/FPAI30TAI图像FPGA/` 的设计与实现：**只讲"怎么做"，尤其是特色设计**，不记踩坑、事故与时间线（那些在一手 `docs/` 里）。

工程定位：复旦微 **悟净 FMQL30TAI**（PS = 4×Cortex-A53，PL = 7 系 FPGA，代理器件 `xc7z030ffg676-2`）上的「SDI 摄像头 → PL 视觉前端 → PS → NPU / VPU → 网页」视觉工程；目标业务是人脸识别 + 防伪 + 内网直播 + 事件录像。

## 篇目

| 篇 | 文件 | 覆盖的组件 |
|---|---|---|
| 01 | `平台与数据流.md` | SoC 与内存、SDI 采集链、网口、启动链、整条数据流与模块位置 |
| 02 | `视觉前端RTL.md` | 整帧选择、VTC 重写、补边、SDI 被动诊断、预览 CSR |
| 03 | `人脸与防伪预处理RTL.md` | 仿射采样、五点对齐、CustomOp 接入、PAD 预处理、DDR 读写提交 |
| 04 | `JPEG与MJPEG核.md` | mjpegzero 编码流水、JPEG CustomOp、SDI→JPEG 流、PL JPEG 预览 |
| 05 | `PL网口核.md` | UDP 打包发送、RGMII 收发、MDIO、verilog_ethernet 复用 |
| 06 | `eMMC与存储.md` | eMMC 接 PL 引脚经 EMIO 到 PS SDIO1、分区挂载、人员库布局 |
| 07 | `单所有者摄像头与H264直播.md` | 单 owner 持 SDK/VPU、命令串行、帧租约、请求合并、H.264 硬编与 HLS |

## 阅读顺序建议

- 只想懂**整条链路怎么走**：01 → 07 → 09。
- 要改 **PL 硬件**：01 的数据流图 → 02（前端）→ 03（人脸/PAD）→ 04（JPEG）→ 05（网口）。
- 要动 **PS 软件 / 网页**：07（单所有者与直播）→ 08（模型）→ 09（录像与页面）。
- 要 **出位流 / 打包上板**：10 → 06（存储）。
