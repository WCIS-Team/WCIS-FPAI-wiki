# ekho-linux

## 定位

Ekho 开源文字转语音引擎，作为 `repos/lang/tts/ekho-linux/` 子模块存在。仓库说明列出粤语、普通话、客家话、藏语、Ngangien 与 Festival 英语支持，部分语种处于试验状态。

## 入口

- `README.md`：项目说明与构建入口。
- `COPYING`、`LICENSE`：许可文件。
- `src/`、`ekho-data/`、`third_party/`：源码、语音数据与依赖。

本地子模块配置指向 [takomitkm/ekho](https://github.com/takomitkm/ekho)，分支为 `master`。索引不判断子模块工作树是否与远端同步。
