# FunASR 无现成权重清单（14 架构）

结论：以下 14 个架构在 FunASR 中均有代码模块（funasr/models/ 存在），但**没有现成的、可被 FunASR AutoModel 加载的官方或社区权重**。HuggingFace 上同名模型全部为 ESPnet / s3prl / SpeechBrain / HuggingFace-Transformers / sherpa-onnx / asteroid 等其他框架的原生或 ONNX 格式（无 FunASR config.yaml + model.pt 组合），ModelScope 官方 iic/damo 名单中亦无对应条目。按"除超限和无现成权重外都安装"的规则，这 14 项不安装。

核实日期 2026-10-19（2026-10-20 终版复核，14 架构结论不变），方法为 HuggingFace 搜索 API、ModelScope 搜索与官方 model zoo 清单交叉比对。

| 架构 | 裁决 | 依据（含来源） |
|---|---|---|
| eend | 无现成权重 | HF 仅 espnet/diar_ami_eend 等 ESPnet 原生格式；MS 无 iic/speech_eend*；FunASR 官方说话人日志用 SOND（damo/speech_diarization_sond-*）+ cam++，并非 eend。依据 https://huggingface.co/models?search=eend 与官方 modelscope_models_zh.md |
| sa_asr | 无现成权重 | HF 搜索 sa_asr 返回 255 条均为按 token 拆词的无关 ASR；MS 与官方清单无对应条目。依据 https://huggingface.co/models?search=sa_asr |
| lcbnet | 无现成权重 | HF 搜索 lcbnet 0 条结果；MS 无。依据 https://huggingface.co/models?search=lcbnet |
| e_paraformer | 无现成权重 | HF 18 条全为 sherpa-onnx/ONNX 导出；官方流式 paraformer（paraformer-zh-streaming，model_type=paraformer）不使用 e_paraformer 模块（带 pif_predictor 的 PIF-NAR 变体），从未发布权重。依据 https://huggingface.co/models?search=e_paraformer 与 FunASR 源码 funasr/models/e_paraformer |
| transducer (RNN-T) | 无现成权重 | 官方 modelscope 清单"RNN-T 模型"节为空表；funasr 官方 HF 组织 12 个模型无 transducer。依据 https://github.com/modelscope/FunASR/blob/main/model_zoo/modelscope_models_zh.md 与 https://huggingface.co/funasr |
| whisper_lid | 无现成权重 | HF 23 条全为 Transformers 原生 whisper 语种识别微调；FunASR 语种识别由 SenseVoice 内置（zh/en/yue/ja/ko）承担，无独立 whisper_lid checkpoint。依据 https://huggingface.co/models?search=whisper_lid |
| paraformer_v2_community | 无现成权重 | HF 搜索 paraformer-v2 0 条；仅阿里云商业 API paraformer-realtime-v2（闭源）。依据 https://huggingface.co/models?search=paraformer-v2 |
| branchformer | 无现成权重 | HF 51 条全为 pyf98/asapp 的 espnet/s3prl 原生格式。依据 https://huggingface.co/models?search=branchformer |
| e_branchformer | 无现成权重 | 同上，espnet 原生格式，无 FunASR 格式副本。依据 https://huggingface.co/models?search=branchformer |
| data2vec | 无现成权重 | HF 主条目为 facebook/data2vec-audio-* 的 Transformers/s3prl 原生格式；FunASR data2vec 模块无发布权重。依据 https://huggingface.co/models?search=data2vec |
| rwkv_bat | 无现成权重 | HF 仅 JerryAGENDD/RWKV-ASR、yueyulin/rwkv_asr 等独立实验项目（裸 PyTorch，非 FunASR 格式）。依据 https://huggingface.co/models?search=rwkv%20asr |
| conformer_rwkv | 无现成权重 | 无任何 FunASR 格式仓库；源码模块存在但无发布权重。依据同上检索 |
| scama | 无现成权重 | HF 8 条全为无关的诈骗检测文本模型；无 speech/scama-asr 结果。依据 https://huggingface.co/models?search=scama |
| mossformer | 无现成权重 | HF 45 条全为 alibabasglab/MossFormer2_* 语音分离增强（SpeechBrain/asterisk 原生 .pth+hparams），非 FunASR config.yaml 格式。依据 https://huggingface.co/models?search=mossformer |

## 特别说明

- **silero_vad**：ModelScope 无官方 FunASR 格式仓库；FunASR 源码特判 {"silero-vad","silero_vad"} 走 SileroVad，依赖 pip 包 silero-vad（HF 仓库 https://huggingface.co/snakers4/silero-vad，silero_vad.onnx 约 2MB、约 1.6M 参数）。已在校机 venv 安装 silero-vad 6.2.3 并通过 AutoModel(model="silero-vad") 冒烟（SILERO_SMOKE_OK）。按"有权重才装"口径，此项以 pip 包形式落实，无需 ModelScope 仓库。
- **超限排除（参数量>1B，按规则不装）**：qwen_audio（约 8.2B）、glm_asr（约 4B）、qwen3_asr、llm_asr、minmo、Whisper-large-v3（约 1.5B，iic/speech_whisper-large_asr_multilingual 等）、Whisper-large-v2（约 1.5B）。
- **FunASR 官方不支持 zipformer**，故不尝试安装。
- **CT-Transformer-Large 双口径**：详细表写 1.1G、README 表写 290M，实为 290M 参数+大词表 embedding（含 vocab272727 词表），按参数量口径<1B，已装（ct-punc，磁盘 1131.8MB）。
- Fun-ASR-Nano-2512-hf / Fun-ASR-Nano-2512-vllm 为 Transformers/vllm 原生格式，非 FunASR AutoModel 直载格式，不重复安装。

- **ITN 11 项补充（2026-10-20）**：ITN 权重已装（属已装清单，不属本清单），pynini 2.1.7 已由用户经 conda-forge 装于独立 conda env itn（D:\yzd\miniconda3\envs\itn，Python 3.11.17），经 FunASR 仓库旧版 InverseNormalizer API 对 11/11 模型冒烟全部 OK。
