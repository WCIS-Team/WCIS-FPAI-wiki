# 05-录像控制与磁盘守护

## 目的

板端 recorder 默认 quota=4 GiB，当 `/mnt/wcis-data` 自由空间<10GB 时自动停止写入，防止占满 SD 卡影响 OS。

## 守卫机制（disk_monitor）

**脚本位置**：`workenv/ha-small/scripts/disk_monitor.py`

**探测方式**：用 HA REST API `GET /api/mode`（HA 已暴露这个接口，我们只是 POST 它），不 SSH 也不改板端代码；读取 recorder 状态（via `/api/status.disk_free_bytes`）。

**触发条件**：`disk_free_bytes < 10GB (10240*1024*1024)` → POST `/api/mode {mode:off}`

**边界**：
- **只读探测**：不 SSH 也不改板端代码
- **无自动恢复**：一旦触发就停在 off，避免震荡（需要人工确认安全后再切回 auto）
- **留有余量**：guard 阈值 10GB 远高于 recorder quota 4GiB，防止接近上限时写入卡顿

## 短录验证流程

**运行**：
```bash
podman exec ha-small-dev /venv/bin/python /tmp/quick_live_test.py --auto-duration 30
```

**预期行为**：
1. mode 切换到 `auto`，保持约 30 秒
2. 强制切换到 `off`（实验结束，无需等待 guard 触发）
3. 记录帧数变化、盘占增长
4. 人工确认 `df -h /mnt/wcis-data`

## 本次试验结果

| 指标 | 值 |
|---|---|
| auto 时长 | ~30s |
| free disk space | 27.8 GB（稳定） |
| received_frames | 0（无增长） |
| guard triggered | ❌ No |

**结论**：Guard 协议层逻辑 OK（能正确 POST off），但摄像头源未提供 H264 流 → `received_frames` 不变 → 实际写入没发生。待 SDI→PL→PS 链路就绪后再测真实触发。
