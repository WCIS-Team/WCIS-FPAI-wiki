# 芯片

> **本页回答什么问题**：FMQL30TAI 这颗芯片自身提供什么（处理器、NPU、可编程逻辑、DMA、安全、功耗、GT），哪条规格在本设计里承担什么，以及芯片相关的口径差异（微架构、型号串、FPGA 下沉范围）。
> **本页不回答**：板级接口、PS／PL 归属与到板复核在 [[板子（除芯片）]]；系统与运行环境在 [[PS/psrt&dev/os]]；USB 音箱麦克风一体机在 [[音频]]；NPU 工具链的算子与量化约束在 [[1-NPU模型部署]]；PL 自研模块划分在 [[FPGA自研模块清单]]。本页只登记规格事实，不写开发进度。

## 一、芯片规格

| 项 | 规格 |
|---|---|
| 型号与封装 | FMQL30TAI，FCBGA676，27×27 mm，1.0 mm 焊球间距 |
| 架构 | CPU + NPU + FPGA 异构融合 |
| 处理器 | 4 核 Cortex-A53（E2 实测：MIDR `0x410fd034`、Partnum `0xd03`），最高 1 GHz；L1 32KB 指令 + 32KB 数据；L2 1MB；片上 256KB |
| NPU | 1 个 ZG330 iCore；8 TOPS @ INT8、4 TFLOPS @ FP16、2 TFLOPS @ TF32；精度 INT8／FP16／BF16／TF32；算子 CNN、Transformer 等（实际支持以 ICraft 预检为准，见 [[1-NPU模型部署]]） |
| 可编程逻辑 | 125K 逻辑（LUT 78,600）；BRAM 9.3 Mb；DSP 400 |
| DMA | PS 侧 8 通道（DW DMA）；PL 侧另有独立 AXI DMA（`snps,axi-dma-1.01a`）。通路与地址在 [[板子（除芯片）]] |
| 安全特性 | 专用安全处理器；硬核 RSA/AES/SHA-256/SM4；支持安全启动 |
| 功耗与 IO | 典型 ~8 W；HPIO 150 / HDIO 100 |
| GT 收发器 | 芯片**只有一个 bank 的 GT**（bank112）→ 板上 SDI／SFP／PCIe／SMA 只能四选一，见 [[板子（除芯片）]] |

## 二、芯片在本设计里承担什么

| 规格项 | 在本设计里承担什么 | 关联页面 |
|---|---|---|
| 4 核 Cortex-A53 APU（≤1 GHz） | ALSA／V4L2 采集、NLP／意图路由、身份比对、JPEG 软件编码、网络与云端调用 | [[板级管线详图]] |
| PL 侧 125K 逻辑／LUT 78,600 | A 视觉前端 + B 音频前端 + C 控制集成的自研空间 | [[FPGA自研模块清单]] |
| BRAM 9.3 Mb | 行缓存与阶段间缓存的物理载体（本体用厂商 BRAM／FIFO IP） | [[FPGA自研模块清单]] D2 |
| DSP 400 | resize／色彩矩阵／FIR（若 SRC 需要）／乘加类预处理 | [[组件选型与复用边界]] |
| NPU ZG330 iCore，8 TOPS@INT8 | ASR／检测／人脸／OCR 推理（须逐个过 ICraft 编译）。**本地 LLM 不在主线用途里**——2026-09-28 按 [[状态源与决策记录#D-25 · 本地 LLM 从主线交付降级为可选演示项\|状态源与决策记录——D-25]] **D-25** 降为可选演示项 | [[组件选型与复用边界]] |

## 三、芯片相关口径差异

| 差异项 | 出现过的写法 | 处理结论 |
|---|---|---|
| 处理器微架构 | 交叉编译与开发流程文档按 `aarch64 / Ubuntu 20.04 / cortex-a7` 配置（`-mcpu=cortex-a7`，并注明"按芯片手册确认"）；组件选型表的 JPEG 理由栏写作"Cortex-A53" | **已闭合**（E2，见 [[板卡镜像实测取证]]）：内核启动横幅 MIDR `0x410fd034`、Partnum `0xd03` = **Cortex-A53**，4 核。编译选项取 `cortex-a53`；`lscpu` 到板复核一次即可（板端环境见 [[PS/psrt&dev/os]]） |
| FPGA 下沉范围 | 旧文档"AFPGA→VFPGA→JPEG→TTS→TOE 五件套"；状态源"JPEG／TTS／TOE 不在当前周期自研范围" | **以状态源为准**（冲突消解规则），详见 [[状态源与决策记录]] |
| dtb 型号串 | 随镜像的 dtb `model = "FMQLMP FMQL100TAI"`，文件名 `fmqlmp-verify.dtb` | 30TAI 复用 100TAI 的**参考设计树**，型号串不代表贴片芯片；且这份树不针对板型裁剪（"`okay` 不等于实板接了"的完整口径在 [[板子（除芯片）]]） |
