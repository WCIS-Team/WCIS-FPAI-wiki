## 二、ICraft 细节

- **v3.36.1**：`FMQL30TAI参考实现\悟净开发板\` 下有两个工程——「单路 PLIN + pHDMI（外置 detpost）参考实现」与「单路 PLIN + VPU 编码_MIG_axi 接口（外置 detpost）参考实现」；安装包覆盖 Linux（amd64 deb / onchip deb）与 Windows（`Icraft_Setup_v3.36.1.exe`），含 `CustomOp_*` 组件、`icraft-3.36.1-cp38` 的 aarch64 / x86_64 / win_amd64 三个 wheel、`IcraftMdzThirdParty` 与 `tags_3.36.1.txt`。
- **v3.39**：`icraft_v3.39.0\` 下是 `30TAI&100TAI.zip`、`30TAI&100TAI_win_python.zip`、`Icraft_Setup_v3.39.0.exe`、`CustomOp_Setup_v3.39.0.exe`、`IcraftMdzThirdParty.deb`、`commit_id.ini`、`tags_3.39.0.txt`。
- **本机已经装好并且用过了**（2026-10-04 才发现；此前"到板前要先装"的判断是错的）：`C:\Icraft\CLI v3.39.0\`（同内容副本 `C:\Icraft\CLI\`），`bin\` 下是 `icraft.exe` ＋ `icraft-parse / -optimize / -quantize / -adapt / -generate / -run / -profile / -docs / -show / -menu.exe` 与 `run_llm.exe`；`icraft --version` → `Icraft 版本: 3.39.0 / CLI 版本: 3.39.0.0-431be90(2608211646)`。`docs\` 有 **5750 个 HTML**（xir 1068／hostbackend 627／utils 547／adapt 277／quantizer 252／xrt 251／zg330backend 198／buyibackend 195／ops 116／axizg330aiu 149／defects 1），其中 `ops\spec\` 是 114 页算子规格页。
  - **算子支持的真值不必上板、也不必等厂商**：PC 上 `icraft compile <toml>` 跑完，直接读各阶段 JSON 的 `ops[].compile_target` 与 `_type_key`；方法与 YOLOv8n 的结果见 [[算子缺口处理#7.1 YOLOv8n 的 D2 三态标注（2026-10-04 本机取证，A 级）|算子缺口处理——7.1]]。首次真编译 2026-10-04 23:07–23:09（Windows CLI），产物在 `wcis-models\modelzoo\yolov8\yolov8_icraft\3_deploy\imodel\ZG\int8\`（`Yolov8n_ZG.json` 304,217 B、`Yolov8n_ZG.raw` 4,722,587 B、`params_md5 09f59e39596e0caa`）。
- **Windows／Linux 的 toml 可移植坑**（2026-10-05 容器实测）：官方 `config/ZG/Yolov8_int8.toml` 里 `forward_list = "./qtset/coco.txt "` 的**值带尾随空格**。Win32 会吃掉路径尾部空格所以能跑；Linux 把它当另一个文件名，`icraft-quantize` 在 `CalibratePass.cpp:1451` 抛 `Exception info : File ./qtset/coco.txt  does not exist` 后终止——**但上层 `icraft` 仍返回 0**，判成败必须看日志里的 `[F]`／`[E]` 行，不能只看退出码。以后"容器里跑不通、Windows 能跑通"先查这类空白符，别怀疑工具链本身。
- **版本还没定**：用 3.36.1 还是 3.39 属**待验证**，判据是"哪个能把我们的候选模型转换通过并给出算子支持表"。第一次转换就按 [[1-NPU模型部署]] 的 A2 记录所用版本，回写 [[状态源与决策记录]]（**事实记录**：本机装的是 3.39.0，3.36.1 从未安装，两次编译都用 3.39.0）。
- **对接口契约的意义**：两个参考实现是核对 PL 侧视频入流（PLIN）、AXI／MIG 接口与 detpost 后处理分工的第一手依据；读通它们是把 [[接口契约与数据通路]] 里的**待验证**项转成**已确认**的前提。
- **注意**：参考实现里的 HDMI／VPU 编码通路属于**平台能力演示**，不等于本项目范围（本项目 JPEG 用 PS 软件编码，不使用 HDMI 输出）。
